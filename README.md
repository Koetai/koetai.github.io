# koetai.github.io

Landing page for the [Koetai](https://github.com/Koetai) GitHub organization,
served at <https://koetai.github.io/>.

Single static page (`index.html` + `style.css`) — no build step. Edit and
push to update.

## Pages setup

GitHub Pages is configured to serve the `main` branch root. No workflow
needed — `index.html` is the entry point.
